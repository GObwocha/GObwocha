### 2.2 Non-Negotiable Content Integrity Rules (`AGENTS.md` §1.4, §2, §3, §10)

1. **Zero Fabricated Biography or Claims:** Never invent academic degrees, years of experience, employer names, client names, awards, or personal backstory.
2. **Zero Fabricated Project Metrics or Outcomes:** Never invent percentages (e.g., `"Increased conversion by 42%"`), revenue numbers, user counts, or latency improvements unless explicitly supplied and verified by the owner.
3. **Zero Fake Social Proof:** Do not include testimonials, client quotes, or company logo strips unless genuine, attributable proof is provided by the owner. Omit those UI sections cleanly rather than rendering placeholder quotes.
4. **Zero Dead or Placeholder Links:** Never render `href="#"`, `href="javascript:void(0)"`, or unverified external URLs (`https://example.com`) as live interactive controls. Optional project links (`liveUrl`, `repositoryUrl`) must be omitted from rendering if not provided.
5. **Explicit `TODO: OWNER INPUT REQUIRED` Markers:** During Sprints 1–5, any unconfirmed owner text in `src/data/site.ts` and `src/data/projects.ts` must include the literal substring `TODO: OWNER INPUT REQUIRED` so both developers and automated release gates can detect every unresolved content item with 100% precision.

### 2.4 Data Architecture & Release-Gate Enforcement Contract

To guarantee that development can proceed through Sprints 1–5 with full TypeScript safety while making it **impossible** to accidentally ship placeholder content to production in Sprint 6, the codebase will enforce the following three mechanisms:

1. **Typed Content Modules (`src/data/site.ts` & `src/data/projects.ts`):**
   - All site copy, biography fields, contact links, and project case studies live exclusively in `src/data/site.ts` and `src/data/projects.ts` (never hardcoded inside deep UI components).
   - Every unconfirmed field is initialized with an explicit `"TODO: OWNER INPUT REQUIRED — <field description>"` value.
2. **Placeholder Asset Isolation (`public/images/placeholders/`):**
   - Any temporary development image used before the owner supplies real project photography must reside inside `public/images/placeholders/` and include `"TODO: OWNER INPUT REQUIRED"` in its metadata description.
3. **Automated Content Release Gate (`S2-T3`, `S5-T2`, `S6-T2`):**
   - A dedicated validation check will scan `src/data/`, `public/images/placeholders/`, and the generated `dist/` HTML files:
     - During Sprints 1–5, the check reports an itemized count of remaining `TODO: OWNER INPUT REQUIRED` markers in `docs/SPRINT_LOG.md`.
     - For the production release checklist (`AGENTS.md` §10 & §11), any remaining occurrence of `TODO: OWNER INPUT REQUIRED` or any reference to `/images/placeholders/` causes the release gate check to **FAIL**, blocking `S6-T3` (Launch) until the owner approves and supplies final content.
